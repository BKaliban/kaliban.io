# Security Policy

This repository is a static personal website. Only the latest version on the `main` branch is supported.

## Reporting a vulnerability

Please report security issues privately via a [GitHub security advisory](https://github.com/BKaliban/kaliban.io/security/advisories/new) or a direct message on [Telegram](https://t.me/k4l1ban). Do not open a public issue.

You can expect an acknowledgement within a few days.
